# Edusaaathi complete project bundle

This bundle contains the editable Next.js project, the static public-site demo, and the original supplied image files.

## Run the editable project

1. Install Node.js 20 or newer.
2. In this folder, run `npm ci`.
3. Run `npm run dev`, then open `http://localhost:3000`.

See `README.md` and `START-HERE.md` for project and configuration notes. The existing `coursesathi.in` site URL is retained in configuration; update it only when the replacement domain is confirmed.

## Static public-site demo

`netlify-demo/` contains a ready-to-drop static public-site demo. It does not include the admin/consultant workspaces, API, or persistent enquiry handling.

## Original assets

`original-assets/` contains the supplied source images. Optimized images used by the website are in `public/images/`.
